# GPU-only video benchmarks at 720p and 1080p — November 5, 2026

Both maintained video models were tested at exact 1280×720 and 1920×1080 output sizes on the RTX 3080 Ti 12 GB / RTX 3080 10 GB pair. CPU execution-weight offload stayed disabled. The existing desktop workflows remain at 512×288; these are isolated resolution screens, not a desktop preset promotion or long-video qualification.

## Results

Each completed clip has 33 frames. Wan runs at 16 fps (about 2.06 seconds); LTX runs at 24 fps (about 1.38 seconds) with audio. Times are individual observations, not medians or a quality-normalized cross-model ranking.

Wan's second 720p request reuses loaded models and conditioning with a new seed. Each LTX request uses a fresh backend and back-half server, because the server ends before VAE decoding. Thus the two LTX columns are independent fresh-worker runs, not a warm-model pair. Seeds are 27001 and 27002.

## Scope and timing

The timer starts at HTTP prompt submission after ComfyUI is ready. It includes the client denoiser load, sampling, VAE decoding, alignment crop, MP4 saving and history polling. Full weight hash checks, ComfyUI startup, LTX back-half server initialization and prompt encoding are excluded. File caches are warm from full checkpoint hash verification. These render timings should not be compared directly with the maintained-entry timings that include fresh GPU prompt preparation and worker startup.

The original GPU-prepared fox-caption conditioning activations are reused. Wan's encoder ran under Torch 2.13 and LTX's under Torch 2.11 in the original November 4 tests; all current renders use the isolated matched Torch 2.11 CUDA 13 environment. Saved activations use CPU storage, while neural model weights execute on GPUs. No new checkpoint, driver, kernel or production environment was installed.

Both latent grids use multiples of 32. Generation therefore runs at 1280×736 or 1920×1088, followed by a bottom-row crop of 16 or 8 pixels to deliver the requested dimensions. No image or video upscaling is involved. The 33-frame temporal length is unchanged.

Wan retains 20 Euler/simple steps, CFG 5 and shift 8. Its regular denoiser is on GPU0 and VAE on GPU1. Regular VAE decoding at 720p exhausted workspace and automatically retried with GPU tiles; both runs completed without CPU weight execution. The 1080p regular path failed during denoising, before decoding. Raylight uses two GPU actors, FSDP, Ulysses 2/ring 1/CFG 1/DP 1, TORCH_FLASH attention and FSDP_CPU_OFFLOAD=false. HD Raylight decoding uses explicit 256-pixel GPU tiles, 64-pixel overlap and temporal 16/4, retaining the GPU denoiser weights. Its clear-VRAM option remains disabled because that path can offload FSDP weights.

LTX retains 8 distilled Euler steps, CFG 1, raw Mesh transport and the tested 28 local /20 remote block split. The owned GPU1 back-half server ends after sampling and before GPU1 VAE decoding. Video VAE tiles remain 128 pixels with overlap 32 and temporal 16/4. The decoded audio contains 63,840 samples at 48 kHz per clip.

## Resources and limits

| Completed path | Minimum sampled free VRAM GPU0/GPU1 | Maximum temperature GPU0/GPU1 | Swap |
|---|---:|---:|---:|
| Wan 720p, both requests | 800 /263 MiB | 67 /52°C | 0 |
| LTX 720p, both fresh workers | 1514 /758 MiB | 59 /52°C | 0 |
| LTX 1080p, both fresh workers | 382 /246 MiB | 63 /57°C | 0 |

The retained guard stops after three bad two-second samples. LTX 1080p dipped below the 256 MiB floor for two consecutive samples in each run, then recovered before a third. It completed within that existing policy; this is a near-limit short-clip result, not comfortable headroom or evidence for longer clips. Wan 720p also has little sampled GPU1 margin. Two-second telemetry can miss brief peaks, including the regular VAE allocation failure that triggered GPU-tiled recovery.

All other guards remain: 32/36 GiB worker RAM high/max, 2 GiB host available floor, 100°C temperature stop, swap writes 1 MiB/s and combined 8 MiB/s over 30 seconds, active full PSI 10% /loading 15%, fail-closed telemetry, one request at a time, idle unload 600 seconds and exclusive GPU ownership. No threshold or communication timeout was raised.

Every parameter-bearing neural module is checked immediately before computation, after FSDP materialization hooks. Completed clips passed GPU-only audits with both physical GPUs observed. No CPU/meta parameter execution was recorded. Wan 1080p regular stopped at the VRAM guard; Raylight's failure was an NCCL collective timeout, not a successful timing or evidence of CPU inference.

One LTX 720p repeat stopped at port preflight due to TIME_WAIT before acquiring GPU ownership. Reuse-address handling was corrected; active listeners remain protected, and the repeat passed. The failed preflight is retained separately in the ledger.

Sampled frames show coherent fox/winter scenes and movement; style differs between models and resolutions. No formal quality ranking was performed. ## Reproduction

Use the existing pinned video runtime and weights from `config/comfy-video-trial.json`. The following commands are benchmark-only; the coordinator rejects these resolution overrides in desktop serving mode. Preserve independent GPU owners and run serially through the visible foreground launcher.

```bash
python3 scripts/visible_terminal.py foreground --title 'Wan HD test' -- /usr/bin/python3 scripts/comfy_run.py --model wan22-5b-raylight --video-stage baseline --video-resolution 720p --foreground-backend
python3 scripts/visible_terminal.py foreground --title 'LTX HD test' -- /usr/bin/python3 scripts/comfy_run.py --model ltx23-mesh --video-stage mesh --video-resolution 1080p --video-seed 27001 --foreground-backend
```

Use `720p` or `1080p`; repeat LTX with `--video-seed 27002` for a separate fresh-worker observation. Conditioning files must be the recorded GPU-prepared activations in the dated benchmark stage directory. All successful artifacts are decoded after saving to verify exact dimensions, frame count and LTX audio.

The forced synchronous-Ulysses retry also failed with NCCL collective timeouts; it did not resolve the 1080p failure and was not selected. Both Ray attempts and the regular-path guard failure remain in the ledger. All 459 CPU checks passed. Final owned workers are stopped and the reservation is released.
