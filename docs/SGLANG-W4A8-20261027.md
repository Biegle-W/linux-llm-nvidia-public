## Numerical and model checks

The final candidate improves prompt processing and first-token latency, but slightly regresses single-request generation. It is not promoted: the maintained W4A16 profile retains its no-speed-loss requirement. These three-request results do not establish performance across all workloads.

The first adapter attached to the AutoRound loader, but this checkpoint is serialized as compressed-tensors. Its activation audit found zero W4A8 projections and rejected it before benchmarking. The corrected adapter uses the actual compressed-tensors route for this checkpoint. A new disabled control was measured after that source change; the initial control and failed activation attempt remain in the numeric/private evidence.

The standalone kernel passed 18 cases: both SM86 cards; K/N 512/1024, 5120/34816 and 17408/5120; M 1/128/384; signed BF16 group128 scales. Maximum normalized RMSE versus the quantized-activation FP32 reference was 0.1753%; versus the original BF16-activation reference it was 0.9644%. Limits were 1% and 3% respectively; all outputs were finite. These are kernel checks, not model-quality equivalence claims.

- `control-ct-w4a16`: complete; 0 audited W4A8 projections; json passed, arithmetic passed, retrieval passed (29,434 input tokens).
- `candidate-ct-mlp-w4a8`: complete; 128 audited W4A8 projections; json passed, arithmetic passed, retrieval passed (29,434 input tokens).
  Relative to fresh W4A16 control: prefill +21.57%, TTFT -17.54%, decode -1.42%.

## Method, isolation and provenance

Linux reported 45.55 GiB usable RAM after one stick was temporarily removed. A fresh W4A16 control and W4A8 candidate use this same hardware state. Do not attribute differences from earlier 64GB runs solely to W4A8. Both final model runs use the corrected isolated package; the only activation switch is `LOCAL_SGLANG_MLP_W4A8=0/1`. The candidate gate excludes attention, heads and MTP, and successful startup requires 128 unique audited MLP projections across both GPUs. Kernel compilation and loading are excluded from inference timing.

A compressed-tensors adapter was written for installed commit `4cb5aebfe08fa0abbd5fbcf84b29ad3d541bd5d3`; the checkpoint is AutoRound-quantized but serialized as compressed-tensors, so the community AutoRound-loader adapter is not applicable. The kernel and shape-guard source comes from [club-3090](https://github.com/noonghunna/club-3090/blob/55961e5c6bd03a4f8ef44fc220d2f3703a1f8b25/models/qwen3.8-27b/sglang/patches/sglang-autoround-w4a8-v0.5.19/README.md). Its unconditional all-eligible-layer activation was replaced with a decoder-MLP-only opt-in. The model checkpoint was not modified. All source hashes are recorded in the numeric file.

Host swappiness stays 60. The bounded worker preserves 30/36 GiB RAM limits, active swap-churn checks, 8 GiB host-availability floor, 1 GiB free GPU floor and 82 C temperature stop. Raw model requests, copied candidate source, compiler cache, service/guard logs and isolation manifests remain private under `data/sglang-w4a8-20261027/`. No candidate was promoted.
