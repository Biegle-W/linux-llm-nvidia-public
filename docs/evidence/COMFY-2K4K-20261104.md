# ComfyUI native2K/4K tests — November4,2026 (America/Toronto)

[Generated image and video samples](../../assets/samples/comfy/README.md). Metadata-free copies preserve the tested media content.

Both maintained image models passed two native2048x2048 generations without CPU
execution-weight offload. Neither native4096x4096 arm produced an image with
the current workflow: Qwen failed GPU0 allocation; FLUX hit the retained GPU0
free-VRAM guard. These failures do not prove that every possible GPU-only4K
implementation would fail. The two cards hold separate components, not a
combined22GiB denoiser allocation.

The original1K defaults, checkpoints, quantizations, engine/driver pins, all nine
LLM entries and resource guards are unchanged. The runtime metadata now records
1024/2048 as tested passing square sizes and4096 as failed under this protocol.
No failed arm was automatically retried with CPU offload or relaxed guards.

## Failure evidence and resources

Qwen4K failed at`SamplerCustomAdvanced` with`torch.OutOfMemoryError` on GPU0
before completing an image. The allocator reported8.23GiB allocated, another
3.00GiB requested and6.19MiB CUDA free. Two-second telemetry missed that
short-lived peak; its sampled minimum free value below must not be mistaken
for the instantaneous allocator headroom. There is no warm4K measurement.

FLUX4K reached the first denoising step, then GPU0 free VRAM remained41MiB for
three consecutive checks. This is below the retained256MiB floor. Host available
RAM and temperature were within their limits, identifying VRAM as the guard
trigger. Its worker was stopped before any output or warm request.

## Reproduction and state

The guarded coordinator now accepts`--size 1024`, `--size 2048` or`--size 4096`.
It validates saved PNG dimensions against the requested size. Existing Desktop
workflows still default to1K. The unchanged1K API graphs were checked against
the coordinator's default output.

```sh
python3 scripts/visible_terminal.py foreground --title 'ComfyUI2K benchmark' -- \
  /usr/bin/python3 scripts/comfy_run.py --model qwen-image-2.1-turbo \
  --size 2048 --foreground-backend
```

Substitute`flux3-klein` for FLUX. A4096 request reproduces the failed native4K
arm; its failure is already recorded and does not need repetition for docs.
Use the corresponding Desktop launcher and change resolution to2048 when using
the UI. Keep only the selected model loaded, and stop the owned instance before
switching launchers. GPU tiled VAE decoding is distinct from CPU weight offload.
