## Protocol and timing definitions

- One warm-up per selected model: 512 reference words, 64 output tokens.
- Three measured prompts use the same deterministic 2000-word reference fixture
  and community-garden generation request across engines. Tokenizer differences
  account for the input-token ranges above. Early unique tags limit prefix reuse.
- Temperature 0, top-p 1, seed 261026, thinking off, one request at a time.
- TTFT: HTTP request to first nonempty content delta on the private loopback
  worker API. Role-only events and keep-alive comments do not count.
- Decode: `(completion_tokens - 1) / (last_content_time - first_content_time)`.
  Speculative engines can batch output chunks; this is observed client stream
  throughput, not isolated kernel throughput. Native decode fields are also
  retained in the numeric record where the engine returned them.
- HyperQwen prefill: prompt tokens divided by the per-request delta of
  `vllm:request_prefill_time_seconds_sum`. Native source defines that interval as
  first scheduled execution through the first generated token, including chunks.
- SGLang prefill: prompt tokens divided by the native
  `sglang:per_stage_req_latency_seconds_sum{stage="prefill_forward"}` delta,
  selecting final pipeline rank 1. Pipeline ranks are not added together and
  `chunked_prefill` detail is not added again. Exact counter snapshots and labels
  are saved. SGLang's small internal non-streaming startup generation overlapped
  the first measured counter window; that entire sample was replaced after
  waiting for internal startup to drain, and the original is retained. The final
  selected timing windows contain one prefill interval each and are checked
  against observed TTFT. SGLang metrics are now enabled for this observability.
- Strata/Maya prefill: engine-provided `prompt_per_second` timing. A prompt/TTFT
  ratio is not substituted for a native prefill measurement.
- Maximum observed reused input: 0 tokens. OS page cache was not flushed.
  Expert caches and their implementations remain engine-specific. Loading,
  cache warmth and request order are not randomized; three repetitions do not
  establish confidence intervals or isolate engine differences across models.

## Settings, versions and resources

The kept numerical model settings, contexts, quantizations and worker budgets
were used. GLM includes its current `MAYA_GLM_RAM_GB=32` cap. Qwen tool-call
parsers remain enabled. SGLang's metrics export is the only observability setting
added for this run; no engine or model was upgraded.

HyperQwen uses vLLM 0.31.0 and Torch 2.13.0; SGLang is 0.5.22 with Torch 2.13.0.
Strata Control/installed component is 0.1.51 (Control commit
`562a0c2ed7169ff6373f893b162106d55a828297`). Maya's version file is 1.1.29,
source checkout `8b4b39f84e35393833b31b80e82bee92e69bb646`. Qualified local
patches remain installed. Hardware is i5-13600KF, 64 GB DDR5, RTX 3080 Ti 12 GB
and RTX 3080 10 GB; both GPUs participate using the retained strategies.

Workers kept their existing 36/48 GiB hard RAM budgets and 1 GiB swap caps.
During the main run, the coordinator sampled system RAM and GPU temperature every five seconds,
with an abort below 8 GiB available host RAM or at/above 82 C. Sampled GPU peaks
were 59/46 C; minimum host available RAM was
10.1 GiB. Maximum system-wide swap occupancy was 1.19 GiB;
this includes unrelated applications and is not owned-worker swap churn.
No resource abort was triggered. Loading/switching periods are included in these
resource observations; this was not a sustained thermal stress test.

The model router and DSH stayed running. A test-owned GPU reservation blocked
other router generation/switching during each measurement block. Native client
activity was not generated by this test. The original HyperQwen default is
restored after measurement. The earlier collector probe stopped on an overly
strict SGLang timing-count check; its warm-up and metric snapshots remain in the
prior dated folder. The final results above use the full run with the documented one-sample SGLang
correction; all original samples remain preserved.
