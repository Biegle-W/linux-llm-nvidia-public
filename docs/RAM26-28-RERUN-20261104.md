## Regression repairs found by the requested full suite

The first CPU invocation used an environment without Torch; the complete run used the installed HyperQwen environment with Torch2.13.0+cu130. The full suite exposed an earlier TensorFold integration regression: Bolt's vLLM busy parser incorrectly required a TensorFold-only gauge. It again requires only vLLM running/waiting gauges and retains fail-closed validation. Existing running/queued/unknown-state and unload tests now pass. Native TensorFold request-state parsing stays scoped to its own watcher.

Old tests were updated to model current bounded cgroups, disabled-profile definitions and the 256 MiB floor, with transport health mocked only in CPU fixtures. The active updater list still referenced retired `deepseek-strata`; that component was removed and the independent TensorFold runtime is now explicitly pinned with its exact manifest. Strict coverage tests include rejection of a wrong TensorFold manifest. No update schedule was resumed, no runtime was upgraded and no disabled model was enabled. All 438 CPU checks passed after these repairs.

## Can another engine run this exact IQ1_S faster?

No faster engine is established on this server for these exact new Unsloth files. Installed TensorFold 1.2.2 advertises Flash-Next MLX4-bit/ModelOpt formats, not GGUF. Newer [TensorFold recipes](https://github.com/ashhart/TensorFold/blob/main/docs/recipes/qwen3.8-flash-next.md) also discuss EXL3/NVFP4 paths; those require different checkpoints and independent memory/quality qualification. The fast Qwen27B DFlash2 result cannot be transferred to Flash-Next IQ1_S.

Strata supports Flash-Next and IQ kernels, but its published [Unsloth1-bit release support](https://github.com/Niko1221/Strata/releases/tag/v0.2.9) is explicitly for **DeepSeek**. That is not proof that the Flash-Next loader/kernels support the new v3.1 IQ1_S mixture. It is a candidate for a compatibility audit before any GPU comparison, not a promised speedup. [Maya's current model list](https://github.com/mw00/project-maya) lists GLM, DeepSeek and MiniMax rather than Flash-Next. No alternate runtime was installed or weights converted during this RAM rerun.
